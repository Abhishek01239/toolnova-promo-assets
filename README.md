# Minecraft Shorts Engine

Code-only production pipeline for Minecraft-style YouTube videos: procedural voxel 3D scenes,
narration-synced direction, original synthesized music and sound effects, animated captions,
and an automatic quality check. Shorts render at 1080×1920; long videos at 1920×1080.

No game assets are used: textures, characters, music and SFX are all generated by code.
"Minecraft" is a trademark of Mojang/Microsoft; this is unofficial fan content.

## Setup
```bash
bash scripts/setup.sh
```
This installs ffmpeg, the headless OpenGL libraries (Mesa llvmpipe, no GPU needed), fonts and Python
packages, and downloads the free Kokoro voice model into `models/` (~350 MB, git-ignored).

## Voices
| Option | Cost | Notes |
|---|---|---|
| Kokoro (`mcengine/tts.py`) | Free, local | Apache-2.0, OK for monetized videos. Voices: `am_puck`, `am_michael`, `am_fenrir`, `am_adam`… |
| ElevenLabs | Credits | More expressive; supports `[excited]`-style tags. Word timings from ElevenLabs Scribe. |

## Modules (`mcengine/`)
| module | what it does |
|---|---|
| `textures.py` | Procedural 16×16 block & character textures in one atlas |
| `geometry.py` | Textured box meshes, voxel mesher with face culling + ambient occlusion |
| `models.py` | Hero "Pip", Creeper-style mob, block entities; poses (walk, punch, wave, flail, reach) |
| `renderer.py` | moderngl/EGL renderer: sky, sun/moon, stars, lit + fogged voxels, particles, bloom, grade |
| `lighting.py` | Time-of-day presets (day → golden → night → dawn) |
| `anim.py` | Easing, keyframe tracks, camera orbit/shake, stateless particle bursts |
| `overlay.py` | Shorts captions with word highlight, title pops, colour emoji, hearts HUD, hotbar |
| `audio.py` | Synthesized SFX, procedural music by section, mixer with voice ducking + limiter |
| `voice.py` | Script parsing, ASR word alignment, silence fallback, `cue(word)` lookups |
| `tts.py` | Free Kokoro narration with per-line timing |
| `render.py` | Frame loop → ffmpeg (x264) and muxing |
| `qc.py` | Resolution, black frames, silence, loudness (EBU R128), full decode, contact sheets |

## Episodes
`projects/one_block_hardcore/` is Episode 1, "I Survived ONE Block in the Sky… in HARDCORE".

```bash
cd projects/one_block_hardcore
python build.py stills 1.0,12.5,33.4   # quick visual check -> work/stills.png
python build.py all                    # full render -> output/ + QC report
```
A full 50-second Short renders in about 10 minutes on 4 CPU cores.

## Making a new episode
1. Copy `projects/one_block_hardcore/` to a new folder.
2. Write `LINES` (the narration) in `story.py`.
3. Generate the voice: Kokoro via `mcengine.tts.synthesize(LINES)`, or ElevenLabs plus `assets/words.json`.
4. Anchor every event to narration words with `cue("word")`: actors, `camera(t)`, `frame_spec(t)`,
   `draw_overlay(t)`, `sfx_events()`, `music_sections()`.
5. Check with `stills`, then run `all`.
